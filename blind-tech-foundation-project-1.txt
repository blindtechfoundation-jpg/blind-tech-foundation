# Blind Tech Foundation

An offline-first, accessibility-focused web app (installable as a PWA on Android) for blind and
visually impaired users. Runs entirely in the browser with no external network calls except for
the optional integrations listed below, which you can add yourself.

## Files in this project
- `index.html` — the entire application (HTML, CSS, and JavaScript in one file)
- `manifest.json` — PWA manifest so it can be "installed" to the home screen on Android
- `sw.js` — service worker that caches the app for offline use

## Deploying
1. Put all three files in the root of a GitHub repository (or a `docs/` folder for GitHub Pages).
2. Enable GitHub Pages on that repo/folder.
3. Visit the Pages URL on an Android phone in Chrome, then use "Add to Home screen" to install it
   like an app. It will keep working offline after the first visit because of `sw.js`.
4. No build step, npm install, or server is required — it is plain static files.

## What is fully working right now (no setup needed)
- Text-to-speech reading with live word highlighting, sentence skip/rewind, file import (.txt/.md/.csv/.html)
- Voice typing (speech-to-text)
- Camera capture and photo download
- GPS coordinates (latitude/longitude)
- A JavaScript code runner (executes JS safely in-browser) and an HTML live preview
- EMI calculator, SIP planner, expense tracker (real math, spoken results, saved locally)
- Banking assistant *demo* form: digit-by-digit account read-back, spoken word-amount confirmation,
  downloadable text receipt (this does **not** move real money or talk to a real bank)
- Rule-based Needs Advisor and a small local FAQ/Troubleshoot search
- Extractive text summarizer and flashcard generator that process your actual pasted text
  (no AI service — a real, deterministic on-device algorithm)
- Voice/typed to-do list, medication time reminders (while the tab is open), Emergency SOS
  (opens the phone dialer to a saved number after a confirmation step)
- Local feedback notes, theme switching (dark/light), search, navigation drawer, bottom nav

All of the above is saved locally in the browser via `localStorage` — nothing leaves the device.

## Features that need an external service before they will work
These are **not** faked with placeholder output. Each one is wired up in the UI, clearly labeled
in the app, and calls out to an empty stub function you need to fill in. Search `index.html` for
these exact function names to find where to add your integration:

| Feature | What it needs | Stub function / location |
|---|---|---|
| OCR text extraction from photos | A cloud OCR/vision API (e.g. Google Cloud Vision, Azure Computer Vision, or an on-device model bundled separately — too large to inline in one HTML file) | `runOcr(imageDataUrl)` — currently just a comment near the Camera section |
| AI scene/image description | A multimodal vision-language API (e.g. the Claude API with an image input) | Same `runOcr()` stub — extend it to also request a description |
| Neural / non-system voice synthesis | A TTS API (e.g. ElevenLabs, Google Cloud TTS, or Kokoro hosted behind your own backend) | Add a second branch in the voice logic near `playFrom()`; currently only the device's built-in `speechSynthesis` voices are listed |
| AI-generated exam Q&A | A text-generation API (e.g. the Claude API) | `callExamAPI()` — button is present but disabled until this is implemented |
| Python / C++ code execution | A sandboxed code-execution backend (e.g. Judge0, Piston, or your own containerized sandbox) — running arbitrary code in a browser is not safe | `callExecAPI(lang, code)` — JavaScript already runs directly in-browser; other languages show a clear "requires backend" message instead of pretending to run |
| Spoken street address / nearby places from GPS | A geocoding + places API (e.g. Google Maps Platform, Mapbox, OpenStreetMap Nominatim) | Extend the `locBtn` click handler — it currently only reads out raw latitude/longitude |
| Real bank transactions | A bank's own authenticated API/SDK — this is a serious security and regulatory undertaking, not something to bolt onto a demo app | The Banking Assistant section is explicitly a local practice form; do not repurpose it for real transactions without a licensed banking integration |
| Automatic/monitored emergency dispatch | A tested telephony or emergency-services API/partnership | `sosConfirm` currently opens the native phone dialer (`tel:`) after user confirmation, which is the safe default; true automatic dispatch requires a vetted, tested integration |
| Background reminders when the app/tab is closed | Push notifications require a backend push server and, for a true native experience, wrapping this PWA with a tool like Capacitor/Trusted Web Activity | Reminders currently only fire while the page stays open, via `setInterval` |
| Live community forum | A backend server + database + moderation | Feedback is currently saved to `localStorage` only, per-device |

## Security notes
- No data is transmitted anywhere by default — everything lives in the browser's `localStorage`.
- If you add any of the API integrations above, store API keys server-side (e.g. in a small proxy
  you control) rather than embedding them directly in this client-side file, since anything in
  `index.html` is visible to anyone who views page source.
- The Banking Assistant is a **local practice form only**. Do not enter real account credentials
  or connect it to a real bank without a proper security review and licensed integration.

## Accessibility
- All interactive elements have `aria-label`/visible labels and meet a 48px minimum touch target.
- Live regions announce state changes (`aria-live`) for TalkBack.
- Works with Android TalkBack; theme toggle includes a light option for low-vision users who
  prefer light backgrounds.

function numberToWords(n){
  const a=['zero','one','two','three','four','five','six','seven','eight','nine','ten','eleven','twelve','thirteen','fourteen','fifteen','sixteen','seventeen','eighteen','nineteen'];
  const b=['','','twenty','thirty','forty','fifty','sixty','seventy','eighty','ninety'];
  function two(num){ if(num<20) return a[num]; return b[Math.floor(num/10)]+(num%10?'-'+a[num%10]:''); }
  function three(num){ let s=''; if(num>=100){ s+=a[Math.floor(num/100)]+' hundred '; num%=100; } if(num>0) s+=two(num); return s.trim(); }
  if(n===0) return 'zero';
  n=Math.round(n);
  let parts=[];
  const crore=Math.floor(n/10000000); n%=10000000;
  const lakh=Math.floor(n/100000); n%=100000;
  const thousand=Math.floor(n/1000); n%=1000;
  if(crore) parts.push(three(crore)+' crore');
  if(lakh) parts.push(three(lakh)+' lakh');
  if(thousand) parts.push(three(thousand)+' thousand');
  if(n) parts.push(three(n));
  return parts.join(' ')+' rupees';
}

===== FILE: sw.js =====
const CACHE_NAME = 'btf-cache-v1';
const ASSETS = ['./', './index.html', './manifest.json'];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS)).catch(() => {})
  );
  self.skipWaiting();
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((k) => k !== CACHE_NAME).map((k) => caches.delete(k)))
    )
  );
  self.clients.claim();
});

self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((cached) => cached || fetch(event.request).catch(() => cached))
  );
});
